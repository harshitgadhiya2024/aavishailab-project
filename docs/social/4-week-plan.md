# Aavishield prelaunch — 4-week social plan

**Window:** Mon 2 Nov → Sat 28 Nov 2026. Launch day: **Fri 27 Nov**.
**Platforms:** Instagram (feed + Stories), LinkedIn (company page + founder), X.
**Assets:** 14 posts in Figma, https://www.figma.com/design/3n8hA2SOednIADOfANuNwv. All are 1080×1350 (4:5) and work unchanged on Instagram, LinkedIn and X. Renders: `instagram-prelaunch-01.png` … `-14.png` in this folder.
**One goal:** waitlist sign-ups at aavishield.aavishailab.com. Every post ends there.

| Week | Theme | What the audience should feel |

| 1 (2–7 Nov) | Tease | Something is coming from a brand with taste |

## Cadence

- **Instagram:** 3 feed posts/week (Mon, Wed, Fri) + Stories on posting days (repost the feed post, add a "Join waitlist" link sticker).
- **LinkedIn:** same 3 posts from the company page, plus the founder reshares Wednesday's post with a personal note.
- **X:** same 3 posts, shorter copy, plus one text-only thread on Thursday each week.
- **Posting time:** 10:00 IST on Instagram and X, 09:00 IST on LinkedIn (reaches India morning and Europe early).

### Week 3 — The product

**10 Module 01 Web Gateway**
- IG: The web your company approves. Nothing else. / Block by category or domain. Full request log per device. Works off-network, no appliance. / Module 01 of 04. Launching soon.
- LI: Module 01: Web Gateway. Every request leaves the device through the Aavishield agent, so category and domain policy follows the laptop from the office to a hotel lobby. Every allowed and blocked visit is logged against the employee and device.
- X: Module 01: Web Gateway. Block by category or domain, on every network, no hardware.

**11 Module 02 DLP**
- IG: Know exactly what left the building. / Card numbers, IDs, API keys, source code. Reads inside files, PDFs and images. Monitor only, never blocks. / Module 02 of 04.
- LI (founder): The decision we argued about most: DLP that never blocks. Blocking breaks work and gets switched off. Monitoring stays on. So Aavishield records every finding, file and destination within seconds and leaves the business running.
- X: Module 02: DLP. Reads inside files, images and uploads. Flags, never blocks.

**Thread 3 (X, Thu):** Monitor-only DLP: why we never block. 1/ Blocking has false positives. 2/ False positives break work. 3/ Broken work gets DLP turned off. 4/ Off means blind. 5/ Recording keeps you seeing everything, always. 6/ Launch next Friday.
