Activity Monitoring adds context when a finding needs a closer look, and shows which tools teams actually use.

## Off by default

Screenshots are off by default. Your organisation enables monitoring **per device**, never silently for everyone.

## What is captured

- **Periodic screenshots**, not screen recordings.
- **App usage**: which applications were in use, and for how long.

## Screenshot settings

- Interval
- Idle threshold
- Blur
- Retention, which sets how long monitoring data is kept

Admins with the right permission can delete sessions and screenshots.

## Who can see it

Only authorised admins of your organisation. Images are stored in object storage and served only through short-lived signed links.
