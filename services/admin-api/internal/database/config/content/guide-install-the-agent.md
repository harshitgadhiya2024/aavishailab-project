Each employee installs the Aavishield agent from their own portal. There is nothing to push from a server and no network change to make.

## How installation works

1. The employee signs in to the employee portal.
2. They download the native installer for their operating system.
3. They run it. The installer needs administrator rights once, to set up the agent.
4. The device enrolls into your organisation automatically and pulls its policy.

Events from the device start appearing on the console overview within minutes.

## Supported systems

- Recent versions of **macOS**
- **Windows** 10 and 11
- **Linux**: Ubuntu, Debian or Fedora

The same agent and the same policy apply on all three.

## Network requirements

Devices need to reach the Aavishield service to pull policy and send events. No appliances, network changes or VPN concentrators are needed.

## Updates and removal

- Native installers support **automatic updates**, so you never need to reinstall.
- **Uninstalling requires admin approval**, and every uninstall is recorded in the console.
