Application Control stops specific desktop applications from running on enrolled devices.

## Choose the application

There are two ways to pick an app:

1. **Type its name.**
2. **Pick it from the inventory** of applications the agent has seen installed on your devices.

## Choose who it applies to

A rule can target:

- the whole organisation,
- a team, or
- a single employee, for example during an investigation.

## Choose how to block

Use a **network block**, an **app block**, or both. Choose based on whether you want to stop the app from running or from reaching the internet.

## Same rule everywhere

The rule is enforced on macOS, Windows and Linux alike.

## Common uses

- Remove unapproved remote desktop tools that attackers and scammers rely on.
- Keep torrent and personal sync clients off company machines.
