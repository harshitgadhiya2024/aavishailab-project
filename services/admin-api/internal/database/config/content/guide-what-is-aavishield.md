Aavishield is endpoint security for companies. A single agent runs on each laptop or desktop and enforces the policy you set in one web console. It is built by Aavish AI Lab.

## What the agent does

One agent covers seven controls, so you do not need a separate tool for each:

- **Web Gateway**: block and log websites by category or domain, on every network.
- **Data Loss Prevention**: see sensitive data leaving through uploads, messages and email. DLP is monitor-only and never blocks work.
- **Application Control**: stop specific desktop applications from running.
- **VPN Control**: VPNs and anonymizers are blocked by default, with no setup.
- **Malware Scanning**: downloads are scanned while they transfer.
- **Device Posture**: disk encryption, firewall, OS patch level and antivirus are checked on every device.
- **Activity Monitoring**: periodic screenshots and app usage, only on the devices you choose.

## Where enforcement happens

Everything is enforced on the device itself. There is no appliance to install and no traffic to route through an office, so the same policy applies at home, in the office and on hotel Wi-Fi.

## Who it is for

Companies of any size, and especially those without a dedicated security team, that need to protect data on laptops used everywhere.
