## How pricing works

Aavishield is priced **per enrolled device** and billed annually. Count every laptop and desktop that will run the agent, whether Mac, Windows or Linux.

## Which plan fits

| Devices | Plan |
| --- | --- |
| 1 to 50 | Essentials or Business |
| More than 50 | Enterprise |

Use the device picker on the [pricing page](/pricing) to see which plan fits, then book a demo for a quote.

## Start with a pilot

Most customers start with a small pilot group before rolling out to everyone. See [Plan a pilot rollout](/knowledge-hub/plan-a-pilot-rollout).

## Cancelling

Cancellation stops renewal, and the service continues to the end of the paid term. See our [refund and cancellation policy](/refund-and-cancellation).
